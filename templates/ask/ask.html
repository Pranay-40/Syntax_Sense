Frequently Asked Questions

How SyntaxSense guarantees factual, citation-backed code diagnoses.

01 How does grounded vector retrieval prevent AI hallucinations? +

Before Gemini receives your question, your documents and repositories are indexed into 384-dimensional dense vectors using local BGE-small embeddings. The top 8 most semantically relevant chunks are retrieved from Supabase pgvector. Gemini is strictly instructed to generate explanations using ONLY the provided chunk evidence and must attach verifiable [n] citations.

02 What does "Not enough evidence in your sources" mean? +

When the cosine similarity score of all retrieved chunks falls below the 0.60 threshold, the system flags an evidence warning. The assistant explicitly tells you that the documents do not cover the topic, and any diagnostic insights are strictly marked as "From the code only, not from your documents".

03 Is my code or repository ever executed or imported? +

Never. SyntaxSense treats all user-submitted code and repository files strictly as static text data. No code is compiled, executed, imported, or run in a sandbox, preventing code execution attacks by design.
